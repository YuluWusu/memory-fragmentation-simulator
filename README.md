## 📝 Overview

An interactive visualization tool for **memory fragmentation** and **compaction** in computer memory management. This project helps students and developers understand memory allocation algorithms and external fragmentation through visual simulation.

## ✨ Key Features

- 🎯 **3 Allocation Algorithms**: First-fit, Best-fit, Worst-fit
- 📊 **Memory Visualization**: Real-time display of allocated blocks and free spaces
- 🔄 **Compaction**: Merge scattered free spaces into a single continuous block
- 📈 **Detailed Statistics**: Fragmentation ratio, free holes count, used memory
- 📋 **Algorithm Comparison**: Performance comparison between different algorithms
- 📝 **Activity Log**: Record all allocation and deallocation operations

## 🛠️ Technologies Used

- **CSS3** - Styling with Flexbox, Grid, and Animations
- **JavaScript (Vanilla)** - Core logic and interactivity (No frameworks)
